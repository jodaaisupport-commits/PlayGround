Hilfe — So spielst du

  1. Fliegen Desktop: W/S Schub, A/D Gieren, Q/R hoch, F runter, Shift = Boost. C wechselt Kamera.
  2. Fliegen Mobil: Linker 🕹 Joystick = Schub + Drehen, ▲/▼ = Höhe, ⚡ = Boost, 🔥 = Laser halten.
  3. Abbauen: Fliege in den Asteroidengürtel (orange Markierung) und halte Leertaste / Linksklick. Jeder Brocken gibt +6–12 Metall.
  4. Bauen (Tasten 1–6): Station wird vor deinem Schiff platziert. Braucht Metall + Energie.
  5. Kolonisieren: Planet anklicken → „Kolonie gründen“. Kolonien produzieren Credits + Bevölkerung.
  6. Verteidigen: Rote Piraten greifen Stationen an. Zerstöre sie für Credits + Forschung.
  7. Scan (E): Zeigt alle Objekte + Reichweite. Autopilot fliegt zum Ziel.
